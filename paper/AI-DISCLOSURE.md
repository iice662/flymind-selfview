# AI 使用与 Science 的现行规定（投稿前必读，已核实）

**结论：Science 不禁止 AI 辅助，但要求披露；禁止的是 AI 生成科研图像。**
本稿正文由 LLM 起草 → **必须在投稿信 + 方法/致谢中声明，并在方法里给出工具名、版本与提示词**。

## 1. 条文与出处（我实际抓到的原话）

**署名**（CASRAI《AI in Manuscripts: Publisher Policy Landscape》引 Science/AAAS 原文）：
> "AI-assisted technologies such as large language models (LLMs), chatbots, and image creators
> do not meet the Science journals' criteria for authorship and therefore may not be listed as
> authors or coauthors" —— 且 Science 论文中引用的文献本身也不得由 AI 署名。

**披露内容与位置**（同上，Science/AAAS 条目）：
> AI-generated **text, images, and figures must be disclosed, with AI tools named and their
> contribution described**；位置 = **Methods and Acknowledgments**。
> 另据同一份综述的对照表：Science/AAAS 要求 **投稿信里也写明**，并在 **Methods 中披露完整
> 提示词（full prompt）、工具名与版本**。

**现行操作口径**（《科学》主编 Holden Thorp 社论 *Resisting AI slop*，2026-01-01；
科技日报 2026-01-02 报道）：
- 用 LLM **润色/编辑已写好的文字、提升可读性、整理参考文献** → 允许，**无需披露**；
- 用 AI **起草论文正文** → 允许，**必须明确声明**；
- **用 AI 生成科研图像 → 禁止**；
- 审稿人用 LLM 生成评审意见 → 禁止；用 AI 润色自己的评审文字 → 允许但需披露；
- 作者对含 AI 辅助在内的**全部内容**负责；
- Science 与 **DataSeer** 合作核查数据与代码共享合规（这会让第 3 阶段的仓库变成硬要求）。

## 2. 三选一

### 方案 A（推荐）：保留本稿，按政策完整披露
需要三处文字，都已备好，把 `[方括号]` 换成实际值即可。
**(1)(2) 已经写进稿子了**：`paper/cover-letter.md` 的末尾 + `paper/manuscript.md` 的 Methods 末尾
（`**Use of generative AI.**`）与新增的 Acknowledgments 段，你只需替换 `[MODEL NAME/VERSION]`、`[YYYY-MM-DD]`。
第 (3) 项（提示词日志 = Supplementary Note S2）还没写，见下。

**(1) 投稿信里（cover letter，`paper/cover-letter.md` 末尾加一段）**
> **Declaration of generative AI use.** In accordance with the Science journals' policy, we declare
> that the manuscript text was drafted with the assistance of a large language model
> (`[MODEL NAME/VERSION]`, via the DeepSeek Harness, `[YYYY-MM-DD]`); the model was used to draft and
> edit the text and, under the authors' direction, to write the simulation, analysis and
> plotting code. All research data were generated by our own simulations; all code was executed,
> inspected and validated by the authors; every numerical value in the manuscript, tables and
> figures was regenerated from the deposited raw per-trial data by the authors. No AI-generated
> images are included: all figures are direct plots of the authors' data produced with matplotlib
> from the deposited scripts. The authors take full responsibility for the content.

**(2) Methods 末尾（`paper/manuscript.md` 的 Materials and Methods 之后加）**
> **Use of generative AI.** The text of this manuscript was drafted with a large language model
> (`[MODEL NAME/VERSION]`, DeepSeek Harness, `[YYYY-MM-DD]`), used under author direction for drafting
> and language editing. The same model wrote the simulation harness, the statistical analysis code
> and the figure scripts from the authors' specifications; all code was executed and its outputs
> verified by the authors, and the full prompt log is provided in Supplementary Note S2. No
> AI-generated images were used; all figures are programmatic plots of the authors' data
> (`tools/make_main_figures.py`, `tools/make_figures.py`). The authors are responsible for all content.

**(3) Supplementary Note S2：提示词全文（Science 要求 "full prompt"）——已写好**
见 `paper/supplementary-note-S2.md`。它把这份对话里的指令按阶段分组（S2.3 回路与模拟器 /
S2.4 实验harness与配平 / S2.5 分析与报告约束 / S2.6 稿件 / S2.7 政策核查与本注），
每条 = 原文 + 英文 gloss + 它产出的文件/图/表。标记约定写在 §S2.2：
**[as recorded]** = 有会话记录原文（记录本身的省略记为 `…`）；**[recorded form]** = 原话已不可从记录中复原，
给出当时记录的实质内容。想换成逐字原文的是 S2.3.1（数据源）与 S2.4.3（模组规格）两条——
你手上有会话记录，直接替换即可。

### 方案 B：不想声明"AI 起草" → 自己重写正文
政策明确"用 LLM 润色已写好的文本不需要披露"。所以只要正文是**你自己写的**（数字、表、图注、
结构可以照用，它们不是"文本起草"），就无需该声明。工作量：约 3,000 词正文，1–2 天。
做法：用 `paper/manuscript.md` 当提纲，逐段用自己的话写，边写边核对 `results/raw/*.csv`。

### 方案 C：折中
只自己重写**摘要 + 讨论 + 结论**（最容易被看出文风的三处），其余保留并披露。

## 4. 投稿系统的独立 AI 声明栏

Science 投稿系统会单独问"是否使用生成式 AI"。填：
> LLM-assisted drafting of the manuscript text (disclosed in the cover letter, Methods and
> Supplementary Note S2, with tool name, version and full prompt log); no AI-generated images;
> all data, analyses and figures produced by the authors' own code and verified by the authors.

## 5. 顺带一条硬要求

社论提到 Science 与 **DataSeer** 合作核查底层数据与代码共享合规。所以"建仓库 + README +
一键复现 + 逐 trial 数据"不是可选项——请把 `paper/ACTION-LIST.md` 第 3 阶段当作投稿前置条件。
