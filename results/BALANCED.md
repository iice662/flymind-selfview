# 配平后的最终数据（可引用）

> 成稿见 `paper/manuscript.md`（Science 格式），图表数据规格见 `paper/figures.md`，
> 交稿前你要做的事见 `paper/TODO-for-author.md`。

这一份取代此前所有表格。之前的结果里，各臂实际注入的脉冲总量相差 0.1%–42%，
凡是 p ≈ 1e-16 量级的"大效应"都来自这个差异；按下面方式配平后，其中大部分消失。

## 0. 配平做了什么（三处，全部可验证）

1. **不再截断驱动等级**。旧代码 `clamp(level*F, 0, 1)` 在周边细胞需要放大时静默截断，
   于是各臂总量不同（randmat 只有 self 的 0.579/0.731）。现在概率上限只作用在伯努利抽样上
   （`p = pMax·level`，`pMax = 0.075`，等级可到 ~13 才饱和），等级本身不截断。
2. **周边按步求解**，使每一步的注入总量恒等于自然条件：`scale = (target − patchDelivered)/aboveRest`；
   并且**斑块自身不得吞掉超过全部目标**（去相关臂里打乱的信号可能很强而真实转向很弱，
   旧版把周边压到 0 也补不回来，导致该臂总量多 0.6–2.1%，并制造出一个假的"效应"）：
   `patchCap = min(1, target/patchDelivered)`。整流器对非负因子线性，所以这个上限是精确的。
3. **刺激本身逐位相同**：光流/转向序列、它的分块打乱副本、气味背景、抽样的 CX 细胞对，
   全部来自同一个 `Random(90000 + trial_index)`；只有池内的伯努利抽样用各臂自己的随机流。
   于是 `expected`（注入概率之和）在所有臂上**完全相同**。

验证列：`expected`（概率和）、`delivered_mean`（实际注入事件/trial）、`ratio_vs_self`、
`cx_input_syn`（该臂削掉的 CX 输入突触）、`patch_cells`。
